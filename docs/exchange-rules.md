# 换配规则口径

本文件说明工具如何把资料变成标签、预测、换配安排和回测结果。资料字段的定义见
[资料约定](materials.md)。

## 1. 借出标签

一笔借用在观察时点 `asof` 的状态只取决于当日已经可见的事实。

| 状态 | 判定 |
| --- | --- |
| 适配失败 | 完成的复核或退回理由判定为失败 |
| 适配确认 | 复核期限内完成确认 |
| 短期正常归还 | 原计划只借几天并按计划归还，不当作适配问题 |
| 未到复核期限 | 尚无可用的复核结果，且 `asof <= due` |
| 超过期限无反馈 | `asof > due` 仍无结果，单独计数，不当作成功 |
| 晚到确认 | 确认发生在 `due` 之后，不自动当作成功 |

复核表可以对同一理由给出替换结论。只有 `reviews.observed_on <= asof` 的更正才
可见；更正在其发生之前不改写历史标签。

只有前两类进入训练。`reviews.corrected_reach` 是复核时才补录的尺寸，只用于
更正结论，不写回借出时的特征。

## 2. 预测特征

只用借出当日已知的资料：站点、用途、所需配件类别、器具的可调尺寸范围是否覆盖
用户尺寸、场地净宽是否够通过、所需配件类别是否有兼容的器具系列。没有净宽与
没有样本是两件事，分别进入 `unmeasured` 和人工测量。

## 3. 样本支撑与人工测量

模型按“站点/用途/配件/尺寸/净宽/兼容”逐级退让，每一级都要求至少
`--min-support` 个历史样本。任何一级都撑不住时返回人工测量，不输出风险值；
报告会说明是哪一级支撑不足。这样不会为了排满名单而给出看似确信的数字。

## 4. 换配安排

实际调换只接受资料认可的兼容范围：器具站点、合规用途、可调尺寸、通过净宽，
以及配件类别与适用系列。在此之上：

1. **旧承诺优先。** 已签收、未过期或明确改签的保留继续占用主件和共同配件，
   即使当前预测认为风险偏高。
2. **库存以事实为准。** 只有已经核实退回并完成清点（`checked` 事件或
   `parts.checked`）的配件才能用于新保留。已领取未再入库的资产不可用。
3. **主件与配件在同一交接日都要能兑现。** 可调主件换了尺寸也不行，若配套支撑
   件被另一个保留占用，该组合当日不可兑现。
4. **优先级顺序**：旧承诺 → 保护人群 → 失败证据 → 人员确认 → 剩余使用日 →
   可信风险 → 可交接日期。人工测量的个案不进入自动分配。

安排不可兑现时区分原因：`匹配不到`（没有兼容组合，或唯一合适的主件/配件已被
领取未入库）、`交接时间冲突`（组合存在但可交回日期晚于全部交接日，或主件/配件
被未过期保留占用）、`更高优先级`（资产已按上述顺序保留给别的个案）。旧承诺
占用的资产单独标为“资产由未到期旧承诺占用”，便于和“被更高优先级抢走”区分。

## 5. 回测

前向验证：每个观察时点只用此前可见的标签训练，预测之后借出的个案，再对照后来
完成的结论。切分按 `previous` 形成的借用链整组进行，同一次借用的调换和续借不会
一边在训练、一边在回测。指标包括 Brier、对数损失、可靠性与 ECE、误报/漏报
代价，以及有样本支撑的覆盖率；按站点分别统计。`late_unconfirmed`、
`overdue_no_feedback`、`planned_short` 不进入评估，单独列出数量。
